# Gestión de contratos (Frontend)

Aplicación web Angular 21 de DA Soluciones e Inversiones. La guía de uso, la estructura, las decisiones de diseño y la
forma de ejecutarla están en [docs/Frontend.md](../../docs/Frontend.md).

```bash
npm install
npm start     # http://localhost:4200 (necesita la API en http://localhost:5099)
npm test      # pruebas con Vitest
npm run build # compilación de producción en dist/
```
